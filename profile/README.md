# Welcome to Open Development Space (ODS)

Hi there and welcome to Open Development Space! We are a small but friendly organization that aims to make the software we want to see in the world. We don't just tie ourselves to software however we also plan on working in the world of hardware as well.

Checkout our [CONTRIBUTING.md](https://github.com/Open-Development-Space/.github/blob/main/profile/CONTRIBUTING.md) for information on how to contribute!
We have a [SECURITY.md](https://github.com/Open-Development-Space/.github/blob/main/profile/SECURITY.md) that applies organization wide unless a specific repository has their own.
You can find these files in the .github repository in the profile folder.
