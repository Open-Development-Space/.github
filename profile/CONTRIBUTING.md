# How to contribute

All of our public repositories are supposed to be forkable (please create an issue if this is not the case).

## How our repositories are structured
Our repositories use a main branch and a dev branch. Our dev branch is where you should attempt to commit and merge your code as main is designed to hold the stable releases of software. This is so anyone seeking to build from source doesn't have to go looking for the stable build code.

## IMPORTANT! : If a repository uses a different structure for its development and release cycle/schedule it will be stated.
